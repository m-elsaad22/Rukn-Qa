# ملفات شكل الصفحات (Call-main)

الأرشيف `Call-main.zip` هو طقم HTML لشكل صفحات ركن التطور (هيدر، فوتر، هيرو، باحث، بطاقات، 404).  
النصوص داخل الملفات **إماراتية** (دبي، 15 ألف عميل، ضمان 10 سنوات، اتصال 971). تُستخدم كمرجع تخطيط فقط. لا تُنسخ حرفياً إلى موقع قطر.

| الملف | المسار الحي |
| --- | --- |
| `home.html` | `/qa/` |
| `about.html` | `/qa/about/` |
| `contact.html` | `/qa/contact-us/` |
| `faq.html` | `/qa/faq/` |
| `404.html` | أي مسار غير موجود |
| `services.html` / `service-*.html` | `/qa/services/` والمقالات |
| `cities.html` / `city-single.html` | `/qa/cities/` |
| `blog.html` / `article-single.html` | `/qa/blog/` |

سياسة قطر عند تطبيق الشكل: واتساب `971586634710` يبقى، أزرار الاتصال مخفية، بلا أرقام إحصائيات مخترعة، بلا دبي/أبوظبي.
